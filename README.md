# Einherjer's Valheim mods

Bug reports and ideas for the Einherjer mods on Thunderstore: DeathRecap, GroupBoard, HerdBell, IdleBeasts, LoadBearing,
PackBeasts, PenPosts, RavenIsle, ScissorLift, TreeRibbons, Tuneups, WellStocked and Ziplines.

**[Report a bug or share an idea](../../issues/new/choose)**

Please attach your `LogOutput.log` (in your mod manager's profile folder, under BepInEx) from the game session where the
problem happened. It's the quickest way to find the cause.
